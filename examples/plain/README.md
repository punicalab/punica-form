# Form without decorators

A form of `@punica/form-kit` defined with `defineForm` instead of a decorated
class. The project has no decorator setting in `tsconfig.json` or in the Vite
configuration: this is what works in a freshly created project.

```bash
pnpm dev   # http://localhost:5173
pnpm e2e   # builds for production and tests it in Chromium
```
