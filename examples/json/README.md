# Form from JSON

A form that is described as data: the JSON on the left is checked and
rendered by `<JsonForm>` of `@punica/form-kit/json`. This is what an
application does with a form a language model wrote; edit the JSON to see
what is accepted and what is refused.

```bash
pnpm dev   # http://localhost:5173
pnpm e2e   # builds for production and tests it in Chromium
```
